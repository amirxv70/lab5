# Лабораторная работа №5. Сетевые утилиты на Python

Студент: Ашим Амир, вариант 3.

Набор утилит для работы с IP-адресацией: калькулятор подсетей, планировщик VLSM и аудит адресов устройств.

## Состав

| Файл | Назначение |
| --- | --- |
| `netcalc.py` | Калькулятор подсетей, проверка «в одной ли подсети», план VLSM с запасом роста |
| `audit.py` | Аудит адресов устройств по плану адресации |
| `devices.csv` | Список устройств для аудита (с намеренными ошибками) |
| `plan_v3.csv` | План адресации варианта 3 (сеть 192.168.50.0/24, запас роста 20 %) |
| `audit_report.csv` | Результат аудита |

## Требования

Python 3.10 или новее. Сторонние библиотеки не нужны, используются только стандартные модули (`ipaddress`, `csv`).

## Запуск

Калькулятор подсетей (меню):

```
python netcalc.py
```

Пункты меню: 1 — информация о подсети, 2 — проверка двух узлов, 3 — план VLSM.

Аудит адресов:

```
python audit.py plan_v3.csv devices.csv
```

## Коды проверок аудита

| Код | Значение |
| --- | --- |
| E1 | неверный формат IP-адреса или шлюза |
| E2 | неизвестный отдел |
| E3 | IP не входит в подсеть своего отдела |
| E4 | IP совпадает с адресом сети или broadcast |
| E5 | дубликат IP-адреса |
| E6 | шлюз вне подсети отдела |
| E7 | шлюз совпадает с IP самого узла |
| W1 | предупреждение: шлюз не первый адрес подсети |
