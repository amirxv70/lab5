Набор утилит для работы с IP-адресацией и диагностики сети: калькулятор подсетей, планировщик VLSM, аудит адресов устройств, пошаговая диагностика подключения, параллельная проверка сервисов и единая утилита командной строки.

## Данные варианта 3

- сеть для VLSM: `192.168.50.0/24`
- отделы: Цех — 90, Офис — 30, IT — 10, Камеры — 25 устройств
- запас роста: 20 %
- порт веб-сервера: 8030

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `netcalc.py` | Калькулятор подсетей, проверка «в одной ли подсети», план VLSM с запасом роста, проверка плана, агрегация маршрутов |
| `audit.py` | Аудит адресов устройств по плану адресации (коды E1–E7, W1) |
| `netdiag.py` | Пошаговая диагностика подключения «снизу вверх» с журналом `diag_log.csv` |
| `services.py` | Последовательная и параллельная проверка доступности сетевых сервисов |
| `netkit.py` | Единая утилита командной строки с подкомандами `calc`, `vlsm`, `audit`, `diag`, `services` |
| `tests/test_netcalc.py` | 17 модульных тестов |
| `plan_v3.csv` | План адресации варианта 3 (создаёт программа) |
| `devices.csv` | Список устройств для аудита (с намеренными ошибками) |
| `audit_report.csv` | Результат аудита |
| `diag_log.csv` | Журнал диагностики |

## Требования

Python 3.10 или новее. Сторонние библиотеки не нужны, используются только стандартные модули.

## Примеры команд `netkit.py`

Справка:

```
python netkit.py -h
python netkit.py vlsm -h
```

Калькулятор подсети:

```
python netkit.py calc 10.0.0.5/26
python netkit.py calc "10.0.0.5 255.255.255.192"
```

План VLSM варианта 3:

```
python netkit.py vlsm 192.168.50.0/24 "Цех=90" "Офис=30" "IT=10" "Камеры=25" --growth 20 --csv plan_v3.csv
```

Аудит адресов:

```
python netkit.py audit plan_v3.csv devices.csv --report audit_report.csv
```

Диагностика сети:

```
python netkit.py diag
python netkit.py diag --gateway 192.168.1.1
```

Проверка сервисов:

```
python netkit.py services
python netkit.py services --parallel --workers 10 --timeout 3
```

## Коды завершения

| Код | Значение |
| --- | --- |
| 0 | всё в порядке |
| 1 | найдены проблемы: ошибка ввода, нехватка адресов, ошибки аудита, неуспешный шаг диагностики, недоступный сервис |

Проверка кода: `echo %errorlevel%` (cmd), `echo $LASTEXITCODE` (PowerShell), `echo $?` (Linux/macOS).

## Коды проверок аудита

| Код | Значение |
| --- | --- |
| E1 | неверный формат IP-адреса или шлюза |
| E2 | неизвестный отдел |
| E3 | IP не входит в подсеть своего отдела |
| E4 | IP совпадает с адресом сети или broadcast |
| E5 | дубликат IP-адреса |
| E6 | шлюз вне подсети отдела |
| E7 | шлюз совпадает с IP самого узла |
| W1 | предупреждение: шлюз не первый адрес подсети |
